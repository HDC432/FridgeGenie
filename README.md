# FridgeGenie - AI Food Management Assistant

FridgeGenie is an AI-powered food management assistant that helps you track your food inventory and generate recipes based on available ingredients.

## Features

- AI-powered chat interface
- Food inventory management
- Recipe generation
- Voice interaction
- Modern and intuitive UI

## Setup

1. Clone the repository:
```bash
git clone https://github.com/yourusername/fridgegenie.git
cd fridgegenie
```

2. Install dependencies:
```bash
npm install
```

3. Create a `.env` file in the root directory and add your OpenAI API key:
```
REACT_APP_OPENAI_API_KEY=your_openai_api_key_here
```

4. Start the development server:
```bash
npm start
```

## Usage

1. Click the chat bubble icon in the bottom right corner to open the AI assistant
2. Type your message or use voice input
3. The AI will help you:
   - Add food items to your inventory
   - Generate recipes based on available ingredients
   - Answer questions about food storage and preparation
   - Engage in casual conversation
